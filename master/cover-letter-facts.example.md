# Cover-letter facts (the only facts make-pack.mjs may use)

Copy this file to master/cover-letter-facts.md (gitignored) and replace every line with
your own facts. make-pack.mjs sends this file to Gemini and tells it to use nothing else;
if a fact is not here, the letter does not say it. Copy numbers exactly as you want them
printed: the script flags any number in the letter that is not in this file.
